# Problem Statement

**SIH26155 – AI Network Security Auditor**

The objective is to analyze Cisco, Fortinet and Palo Alto network configurations, detect security vulnerabilities, calculate a security score, visualize attack paths, and generate AI-based remediation suggestions.

## Objectives

- Parse multi-vendor configurations
- Detect insecure services and ACLs
- Calculate organizational risk score
- Visualize network topology
- Provide AI remediation
